# Handoff: лендинг «Личная CRM»

## Overview
Одностраничный статичный лендинг личной CRM. Единственное целевое действие — перейти в приложение (`https://app.<домен>`). Пять блоков: Hero → Проблема → Решение → Выгоды → Призыв.

**Стек:** Astro + Tailwind CSS 4, статическая сборка (`output: 'static'`), без клиентского JS.

## About the Design Files
Файлы в `reference/` — **дизайн-референсы в HTML**, а не продакшн-код. Задача — воссоздать их в Astro + Tailwind 4. Открыть: `reference/Landing Mobile.dc.html` и `reference/Landing Desktop.dc.html` в браузере (рядом лежит `support.js` — нужен только для просмотра). Все стили в разметке инлайновые — значения ниже взяты оттуда.

`landing-text.md` — исходный текст. Тексты на странице дословные, кроме данных демо-карточки (см. «Контент»).

## Fidelity
**High-fidelity.** Цвета, шрифт, размеры, отступы финальные. Воспроизводить пиксель-в-пиксель.

## Адаптив
- `< 1024px` (база Tailwind) — мобильный макет, проектировался на 390px. Боковые поля 20px, контент тянется на ширину.
- `≥ 1024px` (`lg:`) — десктопный макет, проектировался на 1440px. Боковые поля 80px; контент ограничить `max-w-[1440px] mx-auto` (фон — на всю ширину).
- Между 1024 и 1280 проверить, что сетки hero/решения не ломаются; при необходимости уменьшить h1 (`lg:text-[64px] xl:text-[80px]`).

## Design Tokens
Добавить в `src/styles/global.css`:

```css
@import "tailwindcss";

@theme {
  --font-sans: "Geologica", system-ui, sans-serif;

  --color-page: #eceef5;      /* базовый фон */
  --color-ink: #16182b;       /* основной текст, фон финального блока */
  --color-muted: #4a4d66;     /* подзаголовки, тексты выгод */
  --color-subtle: #5d6077;    /* мелкие подписи, даты */
  --color-accent: #4b4fe0;    /* кнопка, аватар, активная заметка */
  --color-accent-hover: #3c3fc4; /* hover кнопки; цвет ссылок/лейблов/иконок */
  --color-accent-soft: #dfe1fb;  /* фон плашек иконок */
  --color-line: #e3e5ef;      /* разделители внутри белых карточек */
  --color-line-soft: #d4d6ef; /* линия неактивной заметки */
  --color-on-dark: #c4c6dc;   /* текст на тёмном фоне */
  --color-mark-dark: #8f92ff; /* «+» метки кнопки на тёмном */
  --color-accent-hover-dark: #5d61f0; /* hover кнопки на тёмном */
}

body {
  background: linear-gradient(180deg,#eceef5 0%,#e4e6f7 18%,#ebe4f5 36%,#e1ebf4 56%,#e8e6f8 76%,#eceef5 100%);
  color: var(--color-ink);
}
a:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 2px; }
```

**Шрифт:** Geologica (Google Fonts, есть кириллица), веса 300/400/500/600. Лучше self-host через `@fontsource/geologica` или `<link>` в `<head>`.

**Фон страницы:** вертикальный градиент выше на всю высоту страницы (плавный перелив разделяет блоки — линий между секциями нет). Финальный блок — сплошной `#16182b`.

**Скругления:** нигде. Все карточки, кнопки, плашки — прямые углы (`rounded-none`).
**Тени:** только hero-карточка на десктопе: `0 24px 60px rgba(40,44,110,.10)`.
**Белые плитки/карточки:** `bg-white`, без бордера.
**Letter-spacing заголовков:** h1 −0.04em (моб.) / −0.045em (деск.); h2 −0.04em; h3 и имя в карточке −0.02em. Включить `text-wrap: balance` на заголовках, `pretty` на абзацах.

## Компоненты

### Кнопка CTA (`CtaButton.astro`)
Ссылка `<a href={APP_URL}>`, текст «Открыть CRM» слева, «→» справа (`flex justify-between items-center`).
- Моб.: высота 56px, padding 0 20px, ширина 100%, 500 16px.
- Деск.: высота 64px, padding 0 28px, 500 18px. В hero — по ширине контента с `gap: 48px` между текстом и стрелкой; в финальном блоке — на всю ширину колонки.
- Фон `#4b4fe0`, текст белый, hover `#3c3fc4` (на тёмном фоне hover `#5d61f0`).
- **Метки «+»** в 4 углах: `position:absolute`, символ «+», 300 14px/1, смещение `left/right:-5px; top/bottom:-9px`, цвет `#4b4fe0` (на тёмном — `#8f92ff`). Декоративные, `aria-hidden="true"`.
- Prop `variant: 'light' | 'dark'`.

### Логотип
Квадрат цвета accent + текст «Личная CRM», 600. Моб.: квадрат 18px, текст 17px, gap 8. Деск.: 22px / 20px / gap 10. В футере: 14px/15px (моб.), 16px/16px (деск.), цвет текста `#c4c6dc`.

### Иконки
Lucide, stroke-width **1.5**, цвет `#3c3fc4`, в плашке `#dfe1fb`. Используются: `arrow-down-a-z`, `contact`, `notebook-pen`, `search`. Подключить через `lucide-static` / `astro-icon` (`@iconify-json/lucide`) или инлайн SVG (пути есть в референсах). Плашка 40×40 / иконка 22px (моб.), 48×48 / 24px (деск.).

## Секции

### Шапка
`flex justify-between items-center`. Моб. padding 18px 20px; деск. 28px 80px. Справа ссылка «Войти» (400, 14px / 16px, `#3c3fc4`, без подчёркивания) → тоже `APP_URL`.

### 1. Hero
- **Моб.:** колонка; блок текста padding-top 24px, gap 18px. h1 «Помните всех, кого знаете лично» 500 44px/1.02. Абзац 300 16px/1.5 `#4a4d66`. Затем CTA. Ниже, отступ 28px — демо-карточка. Нижний отступ секции 72px.
- **Деск.:** padding-top 96px, сетка `7fr 5fr`, gap 80px, `items-center`. Слева колонка gap 28px: h1 500 80px/1.0; абзац 300 20px/1.5, max-width 560px; CTA (margin-top 8px). Справа — демо-карточка. Нижний отступ 140px.

**Демо-карточка человека** (`bg-white`, колонка) — иллюстрация продукта, не интерактивна:
- Шапка: flex `justify-between items-start`, padding 16 (моб.) / 28 (деск.). Слева: имя «Саша Ковалёв» 500 18/26px; «Дизайнер · конференция, май 2026» 300 13/15px `#5d6077`; строка контактов (flex-wrap, gap 4px 12/16px, margin-top 4/6px, 400 13/15px) — «+7 900 123-45-67», «sasha@kovalev.ru». Справа аватар 40/56px квадрат accent, белые инициалы «СК» 500 14/18px.
- Лейбл «ЗАМЕТКИ»: uppercase, 400 12/13px, letter-spacing .06em, `#3c3fc4`, padding 0 16/28px, снизу 8/12px.
- Заметка 1 (активная): `border-left: 2px solid #4b4fe0`, padding 10/14px 0 10/14px 14/18px. Дата «14 окт» 300 12/13px `#5d6077`; текст «Созвониться после релиза» 400 14/17px/1.35.
- Заметка 2: то же, линия `#d4d6ef`, текст `#4a4d66`: «22 мая» / «Ищет подрядчика на брендинг». Нижний отступ карточки 16/28px.

### 2. Проблема — «Знакомо?»
- h2 500 36px/1.05 (моб.) / 56px (деск.). Отступ до плиток 20 / 40px.
- 3 белые плитки: номер «01/02/03» (400 13/15px, `#3c3fc4`) + текст (400 16/20px, lh 1.45/1.4).
- Моб.: колонка, gap 8px; плитка padding 18px 16px, сетка `28px 1fr`, gap 8.
- Деск.: `grid-cols-3`, gap 12px; плитка padding 32px 28px, min-height 200px, номер сверху, текст прижат к низу (`justify-between`).
- Тексты:
  1. В телефоне записан «Саша Конференция», но кто это, уже не вспомнить
  2. О чём-то договорились на встрече, а через месяц всё забылось
  3. Нужен знакомый из прошлого, но неясно, где его искать: в чатах, в почте или в визитках

### 3. Решение — «Все ваши люди в одном месте»
- Моб.: h2 36px, ниже (gap 20) одна белая карточка из 4 строк; строка padding 16, сетка `40px 1fr`, gap 12, разделитель `1px #e3e5ef` между строками; текст 400 16px/1.45, padding-top 8px (выравнивание по центру плашки).
- Деск.: сетка `5fr 7fr`, gap 80, `items-start`. Слева h2 56px. Справа белая карточка `grid-cols-2`, ячейки padding 32px 28px, колонка gap 24 (иконка сверху, текст 400 18px/1.45); внутренние разделители `#e3e5ef` (правый у левой колонки, нижний у верхнего ряда).
- Пункты и иконки:
  1. `arrow-down-a-z` — Список всех контактов по алфавиту
  2. `contact` — Карточка человека: имя, кто это, откуда знакомы, телефон, почта
  3. `notebook-pen` — Заметки после разговора с датой, новые сверху
  4. `search` — Поиск по имени, который не путается в «е» и «ё»

### 4. Выгоды — «Что изменится»
- h2 36 / 56px; отступ 20 / 40px.
- 4 белые плитки: h3 (500 19/22px/1.2) + абзац (300 15/16px/1.5, `#4a4d66`), gap 8 / 14.
- Моб.: колонка, gap 8, padding 20px 16px. Деск.: `grid-cols-4`, gap 12, padding 32px 28px.
- Пункты (заголовок с точкой — как в тексте):
  1. **Не теряете людей.** Каждый новый знакомый попадает в список, а не теряется в телефоне.
  2. **Приходите на встречу подготовленным.** Открыли карточку и вспомнили, о чём говорили в прошлый раз.
  3. **Держите слово.** Договорённости записаны, а не держатся в голове.
  4. **Быстро находите нужного человека.** Вводите часть имени, и он уже перед вами.

### 5. Призыв + футер
Фон `#16182b`, текст белый, на всю ширину.
- Моб.: padding 56px 20px 48px, колонка gap 18. h2 «Начните с одного человека» 500 40px/1.02. Абзац 300 16px/1.5 `#c4c6dc`. CTA (dark, margin-top 10). Логотип (margin-top 40).
- Деск.: padding 112px 80px 48px, колонка gap 112. Верх — сетка `7fr 5fr`, gap 80, `items-end`: слева h2 72px/1.0; справа колонка gap 28: абзац 20px + CTA на всю ширину колонки. Ниже логотип.
- Текст абзаца: «Добавьте того, с кем говорили сегодня, и запишите, о чём договорились.»

### Отступы между секциями
Секции 1–4 имеют только нижний отступ: 72px (моб.) / 140px (деск.). Видимых разделителей нет.

## Interactions & Behavior
- Все ссылки («Войти», обе «Открыть CRM») ведут на `APP_URL` — вынести в константу/`import.meta.env.PUBLIC_APP_URL`. Открывать в той же вкладке.
- Hover кнопки — смена фона (transition 150ms ease). Hover ссылки «Войти» — opacity .85.
- Focus: `outline 2px solid #4b4fe0; offset 2px`.
- Анимаций, форм, состояний нет. JS не нужен.

Нет.
